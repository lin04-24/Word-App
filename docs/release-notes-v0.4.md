# 默词 v0.4

## 离线英汉词典

- 设置中可主动下载 ECDICT SQLite 词典，下载到应用私有目录；词典不打入 APK，应用更新时保留已下载的数据。
- 下载显示进度，可取消；安装前校验 SHA-256、SQLite 完整性和词条数，并通过原子替换安装。
- TXT 导入的自动词典释义可在设置中开关。已有本地词义不会被词典覆盖；编辑单词时可手动查词并填入释义。
- 设置页注明数据来源并提供 ECDICT MIT 许可文本。

## 版本

- `versionName`: `0.4`
- `versionCode`: `4`
- 离线词典：770,611 个词条，约 174 MiB。
- 正式 APK 必须继续使用现有发布证书，才能覆盖安装旧版并保留本地数据。
